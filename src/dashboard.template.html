How these numbers are counted

Everything comes from the Claude Code logs on this computer (the Claude desktop app's Code tab and the claude command-line tool). Chats on claude.ai and the phone apps are not in these logs, and Claude Code keeps about 30 days of history. Each reply is counted once, including replies from helper agents. Cache reads are context Claude has already seen and re-reads cheaply, which is why totals look large. "Working" adds up gaps of 5 minutes or less between steps. "In the app" comes from the optional focus tracker, which checks once a minute whether Claude is the app in front and you have used the keyboard or mouse in the last 5 minutes; it has no history before it was installed. Nothing on this page leaves your computer.
